# Digital Design with VHDL

This repository presents some essential concepts in digital design, all described using VHDL. The repository is divided into four main folders, as described below.

## Combinational Circuits Folder

Inside this folder, you can find several combinational circuits such as logic gates, adders, multiplexers and demultiplexers, encoders and decoders, comparators, barrel shifters, and binary-to-BCD decoders. All of these circuits are described using different VHDL design methodologies.

## Sequential Circuits Folder

This folder contains the implementation of different sequential circuits such as latches, flip-flops, registers, counters, memories, and finite state machines (FSMs), all written in VHDL.

## Peripheral Interfaces Folder

Several peripheral interfaces have been implemented in this folder, including a 16x2 LCD display, a 4x4 matrix keypad, and seven-segment displays.

## VHDL Libraries Folder

This folder contains essential digital circuits that can be reused for the integration of the different peripherals implemented in the *Peripheral Interfaces* folder. Some of the modules available in this folder include debouncers, pulse generators, and multiplexers for controlling seven-segment displays, among others.

The main goal of this repository is to continue developing new VHDL-based projects involving additional peripherals and communication protocols and other digital interfaces.
